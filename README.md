# Expense Tracker

A lightweight, vanilla JavaScript expense tracker with localStorage persistence, monthly summaries, and Chart.js visualizations.

### Demo
> https://richchidi.github.io/expense-tracker/

### Features
- Add, edit, delete income & expenses
- Monthly income / expense / balance totals
- Category support: Food, Transport, Shopping, Bills, Other
- Balance hide/show toggle (eye icon)
- Recent transactions list with edit/delete actions
- Doughnut charts:
    - Income vs Expenses
    - Expenses by Category
- Data persisted in localStorage
- Mobile responsive

### Tech Stack
- HTML5 / CSS3 / Vanilla JS
- Chart.js
- localStorage (no backend)
